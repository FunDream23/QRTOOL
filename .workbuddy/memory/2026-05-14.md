# 2026-05-14

## 完成的工作

### 产品信息二维码工具 (product-qr-tool.html)
- 创建了一个功能完整的产品信息二维码管理工具（单 HTML 文件，无需部署）
- **功能一：生成二维码** - 填写产品表单（名称、SKU、分类、价格、描述、品牌、库存、备注），一键生成含 JSON 数据的二维码，支持下载 PNG、复制数据、打印、存入产品库
- **功能二：扫码识物** - 调用摄像头实时扫描二维码，自动解析 JSON 并展示产品信息；支持粘贴 JSON 手动解析、上传图片识别二维码
- **功能三：产品库** - 浏览器本地存储管理产品列表，支持导出/导入 JSON 备份、快速从产品库加载到生成表单
### v2.0 升级：分享模式
- **新增"分享模式"**：二维码编码为网页链接而不是纯数据，任何人用微信/支付宝/相机扫码可直接看到精美的产品信息卡片
- **新增产品展示页**：URL 以 `#product=BASE64` 的形式嵌入产品数据，打开页面自动渲染为只读产品卡片，无需任何服务端
- **标准模式 vs 分享模式切换**：标准模式（工具内扫码解析）和分享模式（任何人都能扫码查看）一键切换
- **内置部署指引**：GitHub Pages、内网服务器、Python http.server 三种部署方式说明
- 两不误：既保留工具内部扫码功能，又支持对外分享
- 使用的库：qrcodejs（生成）、jsQR（扫码）
- 纯前端工具，所有数据仅存储在浏览器 localStorage 中
